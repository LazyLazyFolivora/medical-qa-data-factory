# 检索需求覆盖 MVP

目标：从已掌握的可靠材料提出有意义、自包含的问题，覆盖少检索与多路整合需求。focused/parallel/adaptive 是探索意图，不是难度等级、互斥标签或强制配额。同一道问题允许多种检索路径；更短路线不是拒题理由。

本目录是独立实验，尚未替换生产模块 `generation/question_design.py` 及其 `question_strategy`/难度参考。不能据此宣称生产已切换。方法先经过真实模型调用，再决定怎样迁移。

## 方法

1. 整理材料中的完整观察及适用条件，形成可读证据。
2. 一个观察可形成聚焦问题；有意义的互补观察可形成比较、解释或综合问题。不拼接无关事实。
3. 先保证题干自然、范围明确、答案有据，再观察可以怎样检索。
4. 从公开题干出发检索，记录获得了什么、还缺什么、下一步为何需要做。初始查询不得读取私有答案。
5. 达到回答所需的证据覆盖即可停止，不能以“查到预期答案方向”为停止条件。

出题用得到的事实反推问题；检索验证只能从题干正向展开。两个视角必须隔离，否则产生答案泄漏。当前模型自述的检索计划仍有泄漏，不能直接作为动作选择器监督标签。

## 观察到的问题

- 第一轮三个方向收敛到同一比较问题：只换策略名称无法保证信息需求多样。
- focused-v2 答案开头“是”与后文“无显著差异”冲突，又混入干预方式和炎症终点。之后收窄到单个有据观察。
- parallel-v2 核心答案有据，但题干预告“截然相反”，反馈修订后去掉了答案方向。
- adaptive 两轮都没有形成新线索驱动的查询依赖。v2 还问到缺少直接证据的长期纤维化，却说 missing_material=无。这一方向本次未验证成功，不能计为覆盖。
- 修订后的 focused 仍在第二条查询中加入 delay，停止条件也预设延迟；其回答还将组织学评分混称功能指标。这些没有在原始输出中被偷偷修掉。下方整理样例是人工审阅后的版本，不是模型原样产物。

## 两个可保留的问答样例

### 少检索信息需求

问题：在小鼠肾缺血再灌注后，近端小管特异性 EGFR 敲除对肾功能恢复有何影响？

答案：与对照组相比，肾功能恢复延迟。

依据：22418982 P12/P14；BUN 和肌酐恢复情况支持该结论。

题面驱动查询：`EGFR deletion proximal tubule renal functional recovery ischemia reperfusion mice`。

完成条件：找到匹配模型和干预条件、报告相对于对照组恢复结果的可靠证据。不是必须查到“延迟”才停止。

### 多路整合信息需求

问题：在小鼠缺血性急性肾损伤模型中，近端小管特异性 EGFR 敲除与髓系特异性 EGFR 敲除对肾功能恢复的影响有何不同？

答案：近端小管特异性敲除延缓恢复，髓系特异性敲除加快恢复。

依据：22418982 P12/P14 和 40379634 P4。这是两项研究方向的综合，不是直接头对头实验的效应量比较。

另一分支查询：`EGFR deletion myeloid renal functional recovery ischemia reperfusion mice`。

完成条件：两个分支均获得各自干预相对于对照组的恢复结果，并核对物种、损伤类型与终点。

两条查询已通过 web 工具实际执行，返回对应 PubMed/PMC 原论文。全文证据核对沿用保存的原文；没有重新下载每篇全文。工具批量返回不能用于估计每分支排名、成本或统计成功率。这只是可行路线，不证明它是最短或唯一的路线；找到一篇覆盖两侧的综述也可以回答。

来源：https://pubmed.ncbi.nlm.nih.gov/22418982/ ，https://pubmed.ncbi.nlm.nih.gov/40379634/ 。

## 下一步边界

这次证明了同一批材料可以形成聚焦问题和比较问题，并未证明跨实体稳定性或真实 agent 自主采集能力。两题是嵌套信息需求，数据集划分时应按证据簇分组，避免分别进入训练和测试造成泄漏。下一轮应换材料/实体检验需求多样性，并从真实检索缺口观察是否需要继续搜索，而不是再给 adaptive 强凑一个题。
