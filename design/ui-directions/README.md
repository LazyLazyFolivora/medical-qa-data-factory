# UI direction study

Open `prototype.html` directly in a browser. The top-right switch changes between:

- A · Lab White: light laboratory workspace, compact and calm.
- B · Genome Console: restrained dark bioinformatics console.
- C · Academic Press: research-institute editorial direction.

These files are visual studies only and are not connected to the production web app.

`research-workbench.html` is an interactive, browser-openable study for the clean research-workbench direction. It demonstrates idle, running, and completed states with clearly labeled sample data. The implementation plan is in `../../plans/frontend-research-workbench-redesign.md`.

`implemented-research-workbench-evidence.png` is a browser capture of the implemented generation page with an expanded question evidence dossier. It uses the deterministic fixture workflow and is not a live medical conclusion.
