# 固定证据出题 MVP：实验结果与使用方法

日期：2026-11-11。状态：离线实验方案，未接入生产角色路由，未写入题库。

## 本次得到的结果

能形成自然、有据的简单检索题，并能根据具体证据缺陷修订题目。尚未证明当前 Qwen 能稳定完成全自动质量判断，也未证明困难题或跨实体泛化能力。

最终冻结提示后的六个样本（两篇摘要各三次）中，独立审查认为两个可直接保留，四个需局部修订。将具体缺陷反馈给 Qwen 后，四份修订的核心问答均未再发现阻塞性错误。反馈来自独立 agent 审查及原文核对，不是本实验 Qwen 评审稳定检出的结果。

六个样本有明显近重复，是重复实验，不是六道独立题目，更不是六道已发布题目。见 [reviewed-samples.json](reviewed-samples.json)。

## 建议保留的方法

```text
原始材料（保留上下文，句子编号）
    ↓
从实际干预／比较与观察结果形成问题和最小答案
    ↓
必要时转为中文：只改表达，不重新解释证据
    ↓
核对公开范围、干预对象、结果方向、强度与答案完整性
    ↓
通过 → 保留实验样本
有具体缺陷 → 原题＋原文＋具体缺陷 → 最小修订 → 再核对
确实缺证据 → 返回明确缺口，不假装修好
```

第一步的选题方法是“对象／模型与病程—实际干预—报告结果”。问句只公开必要背景和疑问，实际结果留在答案里。不要把完整机制填入题干后只挖掉一个分子名称，也不要为了综合而强行推断独立因果链。

这里的句子编号只是本地原文定位，不是 RAG、外部知识或事实标签。每个编号必须与 source_id 配对。模型用编号引用原句，程序可据此取回原文，避免模型自己改写引文。句子切分目前只针对这两份英文摘要，不是通用论文解析器。

## 可复用的实验提示

- [英文原文出题](prompts/english.md)：先直接依据原文形成问答，不带主 agent 的“证据已经足够”等判断。
- [中文转写](prompts/translate.md)：只转换已有问答，不添加解释或重新选择问题。
- [评审实验提示](prompts/review.md)：先摘录题面实际条件，再核对证据。**已观察到漏检，不应单靠其 PASS 发布。**
- [最小修订](prompts/repair.md)：反馈必须指出具体词句、原文依据和缺口；反馈本身不是证据。

英文起草再转写只是本实验中有可用结果的一种组合，不是所有任务必须经过的语言流程。它增加了一次调用，也会产生外语残留或强度变化。不能宣称比直接中文生成普遍更可靠。

出题调用输入：`evidence_excerpts: [{source_id, sentences: [{sentence_id, text}]}]`、`target_entity`。输出题目、答案及证据编号。翻译调用只接收英文 question 和 answer；证据映射保留自英文版本，翻译后的语义仍需核对。

修订输入：同一份原文、完整 candidate、feedback。修订后是一个新版本，保留旧版本；不能覆盖原始失败样本。反馈发现错误后，先修题目／答案再判断是否可保留，不能只把问题写进 limitations。

## 具体样例

### 原文报告的干预结果

问题：在急性肾损伤向慢性肾脏病过渡的小鼠模型中，药理学抑制 EZH2（使用 3-DZNeP）对肾功能和病理损伤有何影响？

答案：可显著改善肾功能并减轻病理损伤。

依据：[sentences.json](sentences.json) 中 pubmed:37029114 的 S6。来自 `final-primary-repair-3`，修订解决了外语残留及过宽的药理干预表述。这里是材料内的研究结果，不是人体疗效建议。

### 明确范围的副作用查询

问题：在抗癌症治疗期间，表皮生长因子受体（EGFR）被抗 EGFR 抗体阻断时，可能引发哪些电解质流失？

答案：可能导致临床显著的镁和钾流失。

依据：[transfer-sentences.json](transfer-sentences.json) 中 pubmed:32509580 的 S7。来自 `final-transfer-repair-2`，保留了原文 can result 的可能性。

两题都属于单篇直接检索，不应仅因术语专业评为困难。

## 尚未解决的边界

- Qwen 评审曾把来源中的条件当成题干已有条件，漏检物种或病程范围，也曾给出错误的译名修正。增加评审文字或开启思考并未保证解决。
- 最终修订的 `primary-2` 核心问答成立，但第一条 answer_part 写了当前答案未询问的肾功能结果。S6 可用作背景依据，不能当成答案分句。这是证据映射质量问题，仍需修正，未在保存样本中静默替换。
- 本实验只使用两份摘要，均由 EGFR 检索链获得；第二份材料用于迭代，不是严格独立的未见测试集。
- 基线包含旧主 agent 的设计说明，实验改变了提示长度、任务拆分、语言与输出结构等多个变量，只能比较方法组合，不能归因于某一条规则。
- 合格问题仍多为简单题。要探索综合问题，需要实际能连接或比较的材料；不能靠加长题干强造难度。
