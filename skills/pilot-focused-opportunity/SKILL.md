# 选定一个信息需求

解释、需求和题目草稿使用中文，基因符号与原文引句保留原文。

你为未来 query-planner 设计自然检索问题。本轮只探索“识别关系另一端，再了解该对象”的方法，不代表整个数据集只能采用此题型。

阅读原始摘要，选择一条具体观察到的关系：谁调控谁、谁改变什么表型、谁作用于谁。优先选择能帮助读者理解该实体的功能、调控或干预的关系。不能仅因为两个名字共现，就拼接它们的属性；不要把推测的机制当成观察。

把这条关系变成一个有意义的信息需求：先找出符合某个已知效应的对象，再了解它与该效应有关的一般功能。第二部分应帮助理解第一部分的对象，而非随意追加长度、编号、染色体等属性。说明 connection_value。

例如，材料明确说某蛋白的过表达能抑制种子蛋白诱导的细胞死亡，可以补查该蛋白的一般凋亡调控功能。最终问题要求举出这种干预蛋白并解释其一般功能；一般功能不能自动成为该实验效应的已证实机制。不要把这一步退化成再问种子蛋白本身的结构域。

本实验仅提供一次人类 UniProt 定向查询。lookup_entity 必须是单个人类基因符号，lookup_property 必须是一个具体的相关功能需求。若机会需要其他物种、全文或更多检索才能成立，可以返回 assignment=null 并说明原因，不要假装工具能解决。

交付一个 assignment：information_need；relation（fact/source/quote，原文直接摘录）；source_pmid（输入中的 PMID）；lookup_entity；lookup_property；connection_value；question_outline（自然问题草稿，隐藏要识别的对象）。或返回 null。

关系的物种、细胞与操作条件按摘要原文保留，不因补查库为人类就把原实验写成人类。条件不足以唯一识别时，采用“举出一种”并接受有相同支持的其他实例。不要声称穷尽候选或限定唯一答案。不要借材料 ID 代替自然条件。

交接示范（虚构符号）：原文“Overexpression of R inhibits A-induced neuronal apoptosis”，未注明物种。
需求是“举出一种过表达能抑制 A 诱导的神经元凋亡的蛋白，并介绍它的一般凋亡调控作用”。
关系事实只记录“R 过表达抑制该效应”；补查 R 的一般功能。
不能写成“人类 R 是 A 的显性负调控因子”：人类、显性负效应以及直接调控 A 均未由这句话确立。
