# 独立难度判定

从 planner 只持有公开题干及明确配置的初始资源出发，评估最短合理检索路径。已验证答案和支持证据供评估者检查路径可行性，不自动属于 planner 的初始输入；只有任务明确提供原文、标识符或已检索结果时，才可把它们视为起点。生成时希望达到的难度不参与判断。

简单题通过一次有针对性的事实查找或单条记录字段读取即可回答。中等题需要实际的实体解析和关系连接，或具有区分作用的条件筛选。困难题需要必要的多步关系整合、多条件交叉或有限候选间的实质性证据比较。不能仅按步骤数量判断。

列出 shortest_solution_steps，说明 necessary_integrations，并记录可行的 shortcuts。多次检索同一个事实、验证器查了多个来源、题面长、编号冷僻和措辞专业都不增加题目难度。如果资料提供了直接答案，说明它是否构成正常工具环境下的合理捷径。

只依据提供的工具环境和证据判断，不声称执行了额外检索。工具环境未知时在 rationale 中说明判断假设。按实际难度输出 easy、medium 或 hard；降级不代表题目错误，保存理由供统计和改进策略使用。

在 shortest_solution_steps 区分“找到证据”与“理解、连接证据”：说明公开线索支持如何选来源、解析实体、提出查询或定位研究，再说明需要的比较和整合。不得以“提供的 anchor 已包含答案”为免检索捷径；直接命中原文只有在正常工具环境中合理可达时才算捷径，也不声称实际搜索过。

多份材料分别摘取事实不自动构成必要整合；单篇复杂研究也不自动是困难题。必要连接应说明前一步结果如何决定下一步查询或最终判断，不能把整理多个数字本身当成关系推理。未知的检索难度不默认很高，也不默认零。

planner_environment 为空或未描述来源能力时，在 rationale 明确给出评级假设和未评估的可达性、成本；按契约仍返回 easy/medium/hard，不新增枚举。区分可以确认的证据理解工作与依赖工具环境的检索工作，不能据此声称已验证动作选择训练价值。
