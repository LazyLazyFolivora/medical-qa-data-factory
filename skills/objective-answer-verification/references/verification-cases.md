# 答案验证校准案例

以下为虚构关系与验证情境，不是医学事实。示例描述判定逻辑，不提供可直接使用的证据或答案。

## 独立求解一致，但没有证据

独立模型与设计模型都回答 A，但仅有模型输出，没有实际支持材料。

判定：INDETERMINATE。答案一致不能替代独立证据，需检索直接支持。

## 独立求解不同，但可能是别名

候选回答名称 A，独立结果回答名称 B。材料证明两者是同一物种中同一实体的规范名与别名。

处理：按身份比较，可记录为等价答案，不因字符串不一致拒绝。若 B 实际为另一个亚型，则需继续核对范围，不能强行归一。

## 局部唯一与真实竞争答案

问题要求一个满足条件 C 的实体，生成材料只有 A。验证发现 B 也满足相同公开条件，且不是 A 的别名。

判定：REJECTED。单答案设计不成立。可以建议改成多答案或增加真实有据的公开条件，但不能悄悄替当前题目增加条件再判通过。

## 无法证明完整集合

题目要求所有满足 C 的实体，已找到 A 和 B，检索记录显示仍有未访问结果或来源覆盖不明。

判定：INDETERMINATE，不能用“两条支持证据”证明集合只有两项。若已找到遗漏的 C 实体，则当前答案集合有明确缺陷，应拒绝。

## 举例与穷尽要求

题目要求举一个符合条件的实例，A 和 B 都正确。候选回答 A。

处理：B 的存在不推翻 A；检查 A 的证据，并允许其他正确实例。不能因竞争答案列表非空就机械拒绝此类题。若实际题干说“唯一一个”，则必须按唯一性验证。

## 隐藏条件不能修复题目

题目只问某实体的作用，证据却仅支持某物种和实验条件下的作用，而其他条件可能不同。

判定：当前设计缺少必要公开条件，应拒绝并退回设计。验证者不能假定读者会知道隐藏材料里的实验背景。

## 来源重复

验证材料与发现材料有不同 ID，却来自同一原始记录的两个接口。

处理：不能声称独立支持已成立；寻找独立来源或标记独立验证不足。URL 和 ID 的差异不构成独立性证明。

## 科学冲突与执行失败

两份可比研究给出相反结果，无法根据现有材料裁决：INDETERMINATE，并保留双方证据。若任务要求稳定事实，该候选不能继续发布。

provider 超时或预算耗尽：记录执行问题和未完成检查，不能宣称关系不存在，也不能把失败伪装为已完成的反证检索。

## 有条件的通过

公开范围明确，独立可定位证据直接支持候选答案，适用的竞争答案和矛盾检查有真实记录，数量要求有对应依据，且没有关键未决项：可判 VERIFIED。

此时通过的是候选语义；最终题面是否遗漏条件或改变强度仍需另行审核。
