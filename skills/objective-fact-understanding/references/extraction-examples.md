# 事实理解校准示例

以下均为虚构陈述，用于校准提取行为，不是医学事实、真实证据或可发布题目。实际输出只能引用输入中真实存在且可核对的锚点。

## 保留关联与范围

材料：“在人群 P 的观察研究中，暴露 X 与结局 Y 的发生率升高相关；研究无法确定因果关系。”

应保留：X 与 Y 发生率升高的关联；人群 P、观察研究及因果尚未确定是重要条件和强度信息。

错误：X 导致 Y；X 对所有人都有害；X 与 Y 存在已验证机制。

若 P 只是材料内部简称，须从可见内容解析其真实定义；无法解析则报告范围不清，不能给后续题目留下未定义简称。

## 未显著不等于无效

材料：“在剂量 d、持续时间 t 的实验中，两组指标 Z 的差异未达到统计显著性。”

应保留：所述实验条件下的统计结果和比较对象。

错误：处理对 Z 没有任何作用；所有剂量均无效。

谓词若是“报告未达显著性”，这是对报告内容的肯定陈述，不能再随意设置否定极性造成双重否定。极性必须结合完整谓词和对象理解。

## 拆分关系但保留条件

材料：“在物种 S 的细胞类型 T 中，A 与 B 结合，B 定位于细胞区室 L。”

可以形成两条核心关系：A 与 B 结合；B 定位于 L。保留各自实际适用的物种和细胞条件，并指向支持片段。

不能自动形成：A 必然定位于 L；A 通过 B 调控 L 的功能。

共同实体 B 提供后续组合线索，但不证明额外关系。不能把来源没有明确共享的条件复制到所有句子。

## 比较事实不能删掉基准

材料：“在实验条件 C 下，相对对照组 G，处理组 H 的测量值 M 降低，单位为 U。”

应保留：H、M、降低方向、比较基准 G、条件 C，以及实际数值和单位（如果原文提供且与任务相关）。

错误：M 在所有情况下都低；H 能治疗某疾病；没有对照信息的孤立‘降低’。

## 条件差异与冲突

材料一：“条件 C1 下，A 激活 B。”材料二：“条件 C2 下，A 抑制 B。”

先核对 C1 与 C2，不因关系方向不同就认定矛盾。不同条件分别保留；若条件确实相同且结论不兼容，则保留双方引用，标记待核验，不任取一方。

## 重复来源与独立支持

原始报告 R、转载 R 的网页和引用 R 的综述不能自动算三份独立实验。等价陈述可合并出处，但独立性应由来源追溯确定；追溯不了时标记未知。

## 只有弱线索时

标题只出现实体名，正文不可见；或者材料说“未来可能研究 X 与 Y 的关系”。

不能提取为 X 与 Y 存在事实关系。可报告需要正文或实际结果材料；没有可提取事实是合理结果，不用身份常识或猜测补足。
