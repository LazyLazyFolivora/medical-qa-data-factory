# 先形成认识，再概括问题

只使用本次给出的原文content/excerpts。索引是导航，旧笔记、评审、图谱边和模型解释不能代替原文。先记录观察，再概括联系，不先认定结论再找证明。

1. observations按来源记录条件、比较对象、终点、结果和可定位的段落/锚点。不要把不同物种、模型、研究或终点的结果拼成同一次实验。
2. 比较这些观察有什么差异、相互补充或限定关系。是否只是重复叙述？是否共同回答同一个实际问题？无须强求跨论文，一篇研究内的多组对照也可以构成综合。
3. integrated_understanding说明共同支持的认识。明确区分实测结果和解释：总量下降不能直接证明内化；无显著效果不是零效果；疗效差异不自动给出具体机制或贡献比例。避免加入未测量的主因、唯一原因、完全或必然等更强结论。
4. question_focus概括一个信息需求。保持影响答案的条件，不拼多个无关属性；不因为只有一篇论文、问题专业就否定，也不因为术语多便判难。
   不同研究的比较对象或人群不同时，不能把它们当成同一干预在多个背景下的对照。如果一个研究比较给药途径，另一个比较治疗方案，后者不是前者在另一个人群中的直接验证。可以形成关于证据适用范围的问题，不能预设已经建立跨研究的因果比较。
5. answer_boundaries明确不能推出什么。remaining_gaps只列影响当前问题的缺口，不要求解决整篇论文尚未解决的所有机制。缺口可通过原文补齐时说明该读哪个结果/方法段，缺材料时说明要找什么信息。若只有索引，ready_for_design=false。

研究结果是候选理解，非验证结论。事实与解释冲突时以原文为准，出题阶段仍应核对原文。
