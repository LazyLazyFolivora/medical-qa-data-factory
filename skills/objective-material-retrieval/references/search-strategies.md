# 查询与调整策略

查询必须使用当前 provider 支持的字段和语法。下面的表达是查询意图，不是可直接发给所有 provider 的统一语法。

## 六种策略

| 策略 | 触发条件 | 查询与阅读重点 |
|---|---|---|
| 属性查询 | 只有实体，需要建立具体事实方向 | 实体规范名或已确认别名，加一个明确属性；结构化来源优先使用其对应字段 |
| 关系延伸 | 已取得一个相关对象，且延伸可能支持统一任务 | 以已确认对象和目标关系继续查询；记录为什么该延伸与原实体相关 |
| 条件补全 | 关系有线索，但适用范围不清 | 查原始记录或更详细内容，定位物种、人群、实验条件、时间、方向等 |
| 比较探索 | 有合理候选或亚型，需要有依据的区别 | 在相同定义和条件下查各候选的同一属性，不比较不可比的研究结果 |
| 独立支持与冲突检查 | 发现有出题潜力的事实，需要检查可靠性 | 查独立来源和不同结果，追溯上游来源，区分复述与独立观察 |
| 竞争答案搜索 | 候选题需要唯一答案或完整集合 | 搜索满足同样公开条件的其他对象；局部未命中不构成排除依据 |

针对验证的查询应围绕关系和公开条件展开，不能只反复搜索预想答案的名称。存在候选答案时，也要寻找替代答案和不一致结果，避免确认偏差。

## 根据结果调整

| 观察 | 下一步 |
|---|---|
| 空结果 | 检查身份和字段；尝试已确认别名，减少非必要限制；仍无结果则报告并建议更合适来源 |
| 大量泛相关结果 | 加入具体关系、对象或真实条件；不要一次加入所有限制导致失去召回 |
| 只有身份和编号 | 若已满足简单题方向可交接；否则转向功能、关系或过程 |
| 条件不清或只有摘要 | 查详情和原始材料；关键内容不可访问则保留不足状态 |
| 多轮命中同一上游材料 | 标记重复，改查独立来源或不同记录；不要增加支持来源计数 |
| 证据互相冲突 | 核对实体、定义、条件和时间差异，同时保留双方材料，暂不宣布稳定结论 |
| 关联链实体或条件不一致 | 先查连接点，不直接拼成多跳事实 |
| 查询失败或 provider 异常 | 与空结果区分；按调用方重试限制处理，或建议主 Agent 切换来源 |

## 查询示意

输入一个真实蛋白实体后，可以先确认规范身份，再搜索其编码基因；若取得对应材料，可按已确认基因查询定位。每一步都保留来源和物种等条件。若出现多个编码对象，报告歧义，不为了形成单答案题任取一个。

这是探索路径示意，不表示任何特定蛋白必然适合这类题目。若已有可靠来源直接覆盖所需事实，接受该短路径，不为了达到轮数重复搜索。

## 停止与交接

“有足够材料进入事实理解”“具体补查得到回应”“无法在本次限制内解决”是不同结果，需分别说明。

对发现任务，不必穷尽所有方向才能交接；对唯一性、完整集合或反证任务，不可用若干篇相关材料代替相应依据。检索数量、来源数量和预算耗尽都不能单独证明证据充分。

如果没有任何候选直接满足检索需求，返回未选中及原因。不要通过弱相关材料填充结果，也不要为避免空结果改变原有医学问题的含义。
