# 困难题设计

## 设计目标

Planner 需要多步检索、条件交叉或合理候选间的证据比较，才能确定答案并判断证据充分。相对于当前工具环境校准难度，不能仅依据三元组数量或图路径长度命名。

## 从真实信息需求构建查询依赖

本项目按研究后出题：先读取具体观察及实验条件，比较对照与结果，形成有据的综合认识，再反向概括信息需求。不要在没有材料时先编一个复杂问题再寻找证明。一篇研究也可以提供领域问题的证据，但不能仅因它比较了模型、干预或终点，就把该研究的样本结果比较当成出题目标。读者要弄清的应是独立成立的对象关系、差异或解释，保留必要领域条件，而非复述论文的实验流程。不必强制多篇、多跳或候选排除；是否困难由最短合理检索路径另行评定。

先描述一个读者确实需要解决的信息缺口，再选关系，不从“需要三跳”反推题面。可用以下顺序组织短设计说明：

1. 信息需求：为什么要连接这些事实？去掉实体的偶然共现后，问题是否仍有意义？
2. 必要依赖：第一步查到的对象或条件，怎样决定下一步查什么？若各步只是独立取属性后并排列出，不能直接认定为困难。
3. 区分依据：每个筛选条件排除了什么合理候选？排除来自证据，还是仅因当前没搜到？
4. 最短路径：读题中的名称、单条记录或一篇摘要，能否直接答全？允许短路径，并据此降低难度或重新寻找问题机会。
5. 答案边界：为何这些答案足够、为何没有遗漏？只有部分关系记录时，不问现实中“所有相关对象”。

把信息需求、必要步骤和具体缺口简写进 fact_selections.information_gain；必要性尚无依据时写 insufficiency_reason，返回无困难候选。可以另给真正有价值的简单题，但不能把它标成 hard。复杂疾病名称、冷门知识、长列表和读了很多材料都不是必要查询依赖。

## 失败形式与可行改向

- “下列六个名字中哪些属于 X 类？”若名字已经显露分类，主要是辨认，不是困难检索；不要通过增加更多名字修补。若合理候选的分类确实需要外部证据，有限候选题可以成立，仍需按实际查询工作定级。
- “列出与实体 E 相关的所有 X 亚型”：泛化图谱关联和截断检索结果不能界定现实中的完整集合。应先找到有实际意义、证据支持的具体关系或公开比较范围，不能只删掉“所有”掩盖评分仍要求完整列表的问题。
- “根据提供的证据/在明确列举的对象中”：公开题干未包含相应背景时不能成立。补充必要范围不等于把全部解题证据塞入题干。
- 有意义的关系链形式：先从公开、可核验的条件确定对象，再查询该对象在明确条件下的另一项属性或结果。只有前一步确实决定后一步检索、最终答案不能直接查得时才有难度价值。此形式不是现成医学题，不得填入未经支持的关系。

## 方法

先明确核心推理操作，再选择足以支持它的材料：

- 多条件交叉：多个条件共同确定一个对象，每个关键条件都有区分作用。
- 路径比较：比较两条受支持的关系路径，区分介导方式、适用条件或终点。
- 多步推断：关键关系和推断规则均有支持，且实体和条件在各步保持一致。

选择其中适合材料的一种，不要求每题同时满足所有模式。列出关键事实的用途，检查是否有单条直接事实或题面提示绕过核心操作。接受客观有效的短路径，并修改设计或重新分级，不强制绕路。

只有材料明确支持必要性、充分性或干预响应时，才能设计阻断、敲除、反事实干预等题目。“A 激活 B，B 抑制 C”本身不足以保证阻断 B 后 C 的总体变化；其他路径和实验条件可能改变结果。不要把资料缺失当作某路径不存在。

## 校准示例

设计形式：“在〔完整列出的真实候选蛋白〕中，哪些蛋白的编码基因同时位于〔明确染色体〕，且其蛋白产物参与〔有明确定义的生物过程〕？”

这是待真实材料实例化的形式，不是已验证题目。候选必须完整出现在题干中；编码关系、定位、过程参与关系及其适用条件均须有依据。不得用隐藏的内部候选集合限定答案。

检索需求：分别解析候选，连接编码和定位证据，再结合过程参与证据筛选。两个条件都应有真实区分作用，而不是添加无效过滤来显得复杂。

完成条件：题干候选范围内，各候选是否满足条件有足够依据，最终答案集合得到支持。不能因为某候选没被检索到就认定它不符合条件；排除依据不足时不能发布为完整答案。

该形式只有在实际需要交叉整合、没有明显直接答案时才适合困难档。若可靠来源直接给出答案或条件几乎无区分作用，应重新分级。

不合格问法：“哪些蛋白同时满足上述条件？”——题干没有公开条件和候选范围。

不合格问法：“在当前证据中，只有哪个蛋白符合？”——局部检索覆盖不能证明现实中的唯一性。

不合格推断：只凭 A 激活 B、B 抑制 C，便询问阻断 B 后患者 C 水平如何变化。局部关系不足以建立患者总体干预效果。

## 材料不足与复核

若材料只支持孤立属性、缺少必要路径或无法排除合理替代答案，明确返回不支持目标难度及所缺信息。复核题目是否存在受支持的必要整合操作、是否能排除替代答案、是否有明显捷径；不能靠预设读者不知道某个冷僻事实保证困难。
