# 困难题设计

## 设计目标

Planner 需要多步检索、条件交叉或合理候选间的证据比较，才能确定答案并判断证据充分。相对于当前工具环境校准难度，不能仅依据三元组数量或图路径长度命名。

## 方法

先明确核心推理操作，再选择足以支持它的材料：

- 多条件交叉：多个条件共同确定一个对象，每个关键条件都有区分作用。
- 路径比较：比较两条受支持的关系路径，区分介导方式、适用条件或终点。
- 多步推断：关键关系和推断规则均有支持，且实体和条件在各步保持一致。

选择其中适合材料的一种，不要求每题同时满足所有模式。列出关键事实的用途，检查是否有单条直接事实或题面提示绕过核心操作。接受客观有效的短路径，并修改设计或重新分级，不强制绕路。

只有材料明确支持必要性、充分性或干预响应时，才能设计阻断、敲除、反事实干预等题目。“A 激活 B，B 抑制 C”本身不足以保证阻断 B 后 C 的总体变化；其他路径和实验条件可能改变结果。不要把资料缺失当作某路径不存在。

## 校准示例

设计形式：“在〔完整列出的真实候选蛋白〕中，哪些蛋白的编码基因同时位于〔明确染色体〕，且其蛋白产物参与〔有明确定义的生物过程〕？”

这是待真实材料实例化的形式，不是已验证题目。候选必须完整出现在题干中；编码关系、定位、过程参与关系及其适用条件均须有依据。不得用隐藏的内部候选集合限定答案。

检索需求：分别解析候选，连接编码和定位证据，再结合过程参与证据筛选。两个条件都应有真实区分作用，而不是添加无效过滤来显得复杂。

完成条件：题干候选范围内，各候选是否满足条件有足够依据，最终答案集合得到支持。不能因为某候选没被检索到就认定它不符合条件；排除依据不足时不能发布为完整答案。

该形式只有在实际需要交叉整合、没有明显直接答案时才适合困难档。若可靠来源直接给出答案或条件几乎无区分作用，应重新分级。

不合格问法：“哪些蛋白同时满足上述条件？”——题干没有公开条件和候选范围。

不合格问法：“在当前证据中，只有哪个蛋白符合？”——局部检索覆盖不能证明现实中的唯一性。

不合格推断：只凭 A 激活 B、B 抑制 C，便询问阻断 B 后患者 C 水平如何变化。局部关系不足以建立患者总体干预效果。

## 材料不足与复核

若材料只支持孤立属性、缺少必要路径或无法排除合理替代答案，明确返回不支持目标难度及所缺信息。复核题目是否存在受支持的必要整合操作、是否能排除替代答案、是否有明显捷径；不能靠预设读者不知道某个冷僻事实保证困难。
