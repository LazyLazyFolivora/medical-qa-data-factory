# 形成自然问题

从机会和补查材料选择最多三道不同的题。先组织答案，再写题干，再说明求解所需事实。允许少出、不出或全部简单；缺材料的机会保留在 remaining_opportunities。

选题时实际写出事实答案。若只能写“现有材料无法确定”，该机会仍待补查，应放入 remaining_opportunities，questions 可以为空。即使未来 Planner 需要学习不足时停止，本实验也不能把出题者缺资料混作世界事实的答案。

先选最有把握的一题，再考虑是否有第二道知识目标不同的题。三道是容量，不是任务指标。不需要把所有机会转成题；一个机会可以缩小成其中已有明确答案的知识需求。最后的答案应是事实内容，不是“资料没有说”的说明。

对于补查已取得答案的关系机会，保留它的知识目标，不要再次全部缩成摘录题。
如实验指出 B 过表达抑制 A 诱导的某表型，补查又明确了 B 在相应过程中的作用，
可以问“举出一种具有该实验效应的蛋白，并说明它在该过程中的一般作用”。
实际写清细胞类型、操作和表型；不给出 B 的名字。两个回答部分共同帮助理解
干预对象，不要求推断 A/B 直接相互作用。允许其他同样有证据的实例。

来源 ID 放在 evidence_needs.source。题干用真实的实验条件定义任务，不用
“根据 PMID”“在给定材料中”替代条件。如果摘要没提供必要条件就缩小题目或保留缺口。
观察到“到六个月时已经出现”不等于“六个月开始出现”；可询问该观察时间点的表型，
不能把观察窗口变成精确起始时间。物种来自具体证据，不能由种子的数据库物种推及所有实验。

出题示范（A、B、D、C 为教学占位符，不是医学事实）：

- 材料：培养细胞中，删除 A 的结构域 D 后效应消失；物种未说明。
  可问：“在上述类型的培养细胞实验中，A 的哪一结构域对该效应是必需的？”
  实际写作需把“上述类型”和“该效应”替换为材料给出的具体细胞和效应名称。
  答案是 D，难度为直接查询。不因种子源于人类数据库就把实验补成人细胞。
- 材料：A 和 B 均与过程 C 有关，尚无二者功能差异证据。
  交付 remaining_opportunities：“查 A/B 在 C 中的功能差异”。
  questions 中不出现“现有材料是否证明二者有差异”这道题。
- 材料：A 与 B 相互作用，另有 B 的明确功能证据。
  可以围绕已公开的、足以识别 B 的条件询问其功能。若条件不能区分 B，
  先调整为明确举例或保留为机会；不依赖局部图谱替题干确定唯一答案。

例如已知 A 与 B 互作、B 的定位已获支持，可问一个范围明确的关系连接问题；若 B 的定位未知，则保留该机会，改选已能回答的另一项。不要为了交付三题把缺口改写成题目。

好的题干是一个自然的信息需求：对象明确、作答目标明确、条件足够、答案有意义。无需给每题编应用故事。可以直接查询、关系连接、条件筛选、比较或有边界地解释，避免仅把材料主语挖掉。

写作方法：

1. 明确答案内容和边界。表达题区分组织分布、富集程度、条件下变化；比较题明确比较维度；解释题明确现象和需要解释的环节。
2. 用材料实际支持的条件定义问题。涉及细胞实验，应公开细胞类型和操作；不补成一般人体结论。来源用于支撑答案，不用“本数据库中”定义答案。
3. 题干保留需要查明的中间结果，隐藏答案、证据列表和内部 ID。若必须给出有限候选集，其选择应服务于一个自然比较或筛选需求，不能为凑难度任意拼三个名字。
4. 为答案列出必要事实及各自依据，再说明事实间的依赖和何时回答充分。它是参考求解结构，不是强制查询路径。若一份直接资料即可完整回答，应明确承认。

简单题可以只有一项事实需求。中等题应有必要的关系连接、条件匹配或跨材料比较。困难题需要实质的多步或分支整合；术语冷僻、答案较长、生成时查了很多次都不构成难度。

使用同一注释的“定位 A；在条件 B 下定位 C”回答对比，一般仍是直接事实题。若先定位对象、再取得它在条件下的功能证据，才可能形成关系连接任务；也应检查是否有直接短解。

机制由实验或明确解释支撑，不由图谱路径推定。互作实验次数不表示功能影响强度，局部未见不表示不存在。涉及“全部”“唯一”时需要相应依据，必要时改成明确的举例需求。

逐题提供 question、answer、operation、evidence_needs（事实、来源和原文）、dependency、completion、difficulty 及 shortcut。不要声称已通过独立验证。最后写出值得继续探索但资料不足的方向。
