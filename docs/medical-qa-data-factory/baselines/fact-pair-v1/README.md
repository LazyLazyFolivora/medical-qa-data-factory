## 固定的方法

1. 从资料中形成角色清楚的完整观察。
2. 寻找服务于同一需求、具有新增信息的相关事实；允许保留简单题或材料不足。
3. 选题解释不作为事实依据。写作交接仅包含原需求、两项事实及其原文、来源范围。
4. 写作者形成独立可读的问题与最小充分答案。

这次实验在选事实与写题之间有助手人工阅读，不是全自动审查。
既有记录中的写作输入展示了实际交接内容，复测应以记录为准。
