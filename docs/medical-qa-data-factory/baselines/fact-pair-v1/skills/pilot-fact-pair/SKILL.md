# 选择值得提问的事实组合

先理解事实，再决定是否组合。当前任务是为一个给定的信息需求准备候选，不写最终题目。用中文说明，引用保留原文。

第一项 observation 是一条完整的观察句，必须明确谁接受了什么操作、改变了什么、发生在什么条件下。不要分拆成含义模糊的 entity 等标签。主语应是实施操作的对象，效应中写出另一个对象的作用背景。依原文保留“抑制”“促进”“可能”等语义，不交换角色或加强结论。

第二项 added_fact 要带来第一项没有提供的新知识，且服务于同一个信息需求。先问自己：读者已经知道第一项后，第二项具体增加了什么？例如“某操作抑制了某过程”之后再说“对象具有抑制该过程的作用”，增量很弱；若材料说明该对象通常调节哪个环节，就更值得了解。新信息不能只是无关的编号、长度或位置。

两项事实都给出 fact、source、quote。quote 为来源中连续的原文，不自行翻译或拼接。具体实验与人类数据库的一般功能分开，不能把一般功能解释成该实验已证实的机制。实验物种未说明就不添加；不要把摘要没交代的内容说成整项研究不存在。

选择 proposal：pair 表示两项值得共同提问；single 表示只保留一项自然的简单需求；insufficient 表示第一项本身也不足以支持。added_fact 可以为 null，不强制凑两项。用 information_gain 解释新增知识，用 reader_need 说明读者会自然想问什么。不要评价难度，不列与需求无关的机制缺口。

教学例子（虚构事实）：
观察是“过表达 R 抑制 A 诱导的神经元死亡”。资料还说 R 一般调控细胞器膜通透性。
两者可服务于“哪些干预对象有这种效应，它通常调控细胞死亡的哪个环节”的需求。
只说“R 抗细胞死亡”则基本重复已知效应，应考虑只问干预对象。
