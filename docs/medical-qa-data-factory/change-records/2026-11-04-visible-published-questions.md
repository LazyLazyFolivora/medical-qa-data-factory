# 运行中已发布的题目在页面上显示为零

## 现象和原因
ZRSR2 任务中，首道题已通过发布复核，详情接口返回了题面和答案，但工作台在第 336 号断点仍显示零道。列表只读整场任务结束时导出的 questions.jsonl。

## 改动
任务摘要、工作台、运行详情和全局题库同时读取导出行和已提交的运行结果。运行记录必须能从通过且允许发布的复核报告，对应到草稿、冻结合约、答案裁决和已发布的候选。按题目 ID 合并，已有导出行优先。

## 验证
使用真实 ZRSR2 快照验证各视图能读到 U12 型内含子题。回归用例重放生成到发布的断点，覆盖草稿不可见、发布后立即可见和最终导出不重复。Web 接口测试共 24 项通过。
