# 出题后的诊断与修订闭环（2026-11-09）

## 本次要解决的问题

直接原文出题已经接通，但 `revision_of` 只传旧题 ID，设计子 agent 实际拿不到旧题和具体验证反馈。验证也可能把两次模型回答一致当作科学证据，放过答案中的过度机制解释。

## 实现

- FinalQuestionReview 新增兼容字段 repair_issues、recommended_action。每个问题标明题干/候选答案/盲答中的具体句子、问题、来源 ID 和修改建议。提示同时审核候选答案与盲答，不以相互一致代替原文支持。
- 存在未解决问题或 revise/retrieve/abandon 建议时，不产生可发布合同；返回缺口供主 agent 决策。仍由 LLM 判断内容，不添加生物医学关键词判断规则。
- verification_gap 区分 diagnosis（诊断）、repair_issues（修改点）和 evidence_need（真实补证需求），不再把任意评审说明冒充检索需求。
- design_questions(revision_of=...) 自动载入旧候选及最近两轮评审/缺口。按 react_step.sequence 排序，避免持久化字典排序误取旧反馈。只传修订所需字段，不传已验证答案等角色禁止字段。
- 设计模型根据原文修改，生成内容寻址的新候选；保存 question_design_notes 版本关联。新候选必须重新评审、验证和显式发布。旧候选由主 agent 显式关闭，不自动覆盖、继承验证或发布。
- 保留 EXACTLY_ONE 的合同兼容约束。范围/分项冲突现在明确反馈，让模型判断是一个解释的多个部分，还是多个独立答案；未重构整个答案 cardinality 模型。
- 清理 design_questions 工具说明中“没有事实先提取”的矛盾。原文模式无需事实提取；claim_ids 模式才需要。
- 更新主 agent、出题、最终验证的项目 skill。

没有新增一轮强制模型调用。修订和补查仍由主 agent 根据工具结果选择。

## 真实实验，不等同于质量通过

### 完整主循环

`data/runs/repair-loop-live-20261109-1`：真实模型、正式 ReactMainAgent 和生产循环；检索由测试适配器返回固定 PMC5240640 全文。不是联网检索能力测试，不是多论文测试。

首轮 24 步，6 个候选、0 个发布。发生事实提取参数错误、独立检索模式误选、阅读段数错误。模型最终使用直接原文出题，并返回了具体缺口：所选片段没有支持“3.8 倍”的数值，要求读图表。该判断仅针对给定片段，不能推断整篇论文都没有数值。

运行中还尝试了测试适配器不支持的 read_source_details，产生 AttributeError；这属于实验适配器限制，不能据此宣布线上 PubMed 工具损坏。初始运行载入的工具字典尚有旧说明；随后修正说明，另续跑 8 步，结果单独保存到 resumed-result.json。

续跑结束：累计 32 步、8 个候选、0 发布。agent 生成了 ADCC 的 H1975/HCC-827 倍数比较题，候选评审 KEEP，但答案复核因为原文写“NF 比 LF 低 100/17 倍”，而问题问“LF 比 NF 提高多少倍”，要求再找正向措辞。这属于把证据支持误收紧成字面同向表述；同时“活性（EC20）提高”的问法本身应明确为效力提高或所需浓度降低。不能简单靠强行放行解决。主 agent 随后继续读材料，没有完成 revision_of 的自主闭环。此次自主运行仍未证明主 agent 能有效采用新修订通路。

### 旧错误题定向重放

`data/runs/repair-replay-20261109-1`：使用上一轮原样候选及其原文锚点，通过真实模型和正式验证/设计子 agent，进行验证→修订→再验证。为了隔离修订问题，脚本指定调用顺序；不是自主主 agent 成功执行修订的证据，也不发布题目。

原题因答案分项与 EXACTLY_ONE 不一致而返回 INDETERMINATE，语义评审仍给 accept、repair_issues=[]。修订题得到 VERIFIED，但仍把观察到的受体水平变化写成解释完整疗效的确定机制，不能据此计为人工确认合格。该脚本只把模型评审反馈传给修订器，没有传宿主的 cardinality 诊断，因此也不是宿主完整反馈注入的质量实验；完整注入由生产循环测试覆盖。

**结论：修订接口与重新验证通路可用，但语义漏判没有解决，自动稳定出题尚未证明。** 此次不能宣称假通过减少，也不能以测试数替代质量评估。下一步应检查验证实际读到的原文范围（尤其讨论中的替代解释），并做逐断言核对/不同评审设置的对照，而非不断加未经实测的规则。
