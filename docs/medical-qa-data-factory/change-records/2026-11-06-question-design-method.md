# 从真实负例修订出题与评审方法

依据 BRCA1 续跑的 5 个候选，修改实际加载的 objective-question-design/SKILL.md、references/hard.md、objective-candidate-review/SKILL.md，以及主 ReAct skill。

设计前先确定自然信息需求、证据支持和必要查询依赖，用现有 fact_selections 和 insufficiency_reason 承载，不增加 schema 或工程化淘汰规则。明确图谱关联不是医学语义的完整证据、局部邻居不是完整答案集；候选无答案时应报告缺口；改题后必须核对实际题干。

难题方法增加必要依赖、区分依据、最短解题路径与答案范围检查，以及列表分类、无界列举、隐藏背景的泛化负例。没有强制跳数或固定出题模板。

评审区分设计成立、证据充分、实际难度；不因简单或包含公开候选列表一概拒绝。自包含不等于不能检索。医学分类不确定时标明证据缺口，不把名称、模型记忆或风险提示当成事实。主 Agent 提醒避免反复换措辞、加条件而不解决信息需求和证据缺口。

加载机制已确认：出题角色自动载入主 skill、fact-selection 和对应难度参考；评审与主 Agent 自动载入各自 skill。本次仅修改提示资源，不改运行编排、数据与代码。相关 skill 加载和策略测试 23 项通过；尚未完成修改后的真实生成复测，不能据此声称产出质量改善。
