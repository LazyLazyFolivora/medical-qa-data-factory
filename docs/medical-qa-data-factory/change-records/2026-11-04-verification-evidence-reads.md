# 验证时按题目读取证据

## 遇到的问题
验证 ZRSR2 细胞遗传学带区时，模型收到了整条 Ensembl 基因记录，包括 30 个转录本。即使压缩重复外显子，模型仍要处理大量与带区无关的值。

## 讨论过的方案
原始材料保存在运行目录里。模型可以同时看到短字段及其值、长字段的名称和读取引用。字段已经能回答问题时直接判断，缺少关键信息时可以读取本地材料的对应部分，或指出应从别的来源补什么。这样简单查询不必多走一轮模型筛选。

## 实际改动
- 接入独立盲答、反例复核和发布前的证据审查。每个阶段只为本阶段允许看到的引文创建引用。盲答的可读范围在移除发现阶段的锚点后确定。
- 初始证据展示来源、引文 ID、短原值和结构化记录的字段概览。嵌套集合或长文本可以按引用展开。列表按页返回，长文本页标明偏移。模型须根据已读值作判断，信息不够时指出缺口。
- 对两个已指定的 Ensembl 转录本，可以从可见的转录本列表中按注释的外显子 ID 求交集。结果给出比较对象、两侧数量、交集数量和原始行引用。缺少注释时返回缺口。
- 每个可读取证据的阶段最多 4 次模型调用，含最终判断。原始快照和出处保留，旧任务可直接使用新读取方式。

## 如何验证
用任务 `web-2c6974bc-3575-4ff7-b77a-2e8d36cb5fab` 的已存快照离线回放。该批 Ensembl 引文的首轮证据视图为 2,679 个 JSON 字符，显示染色体、坐标和组装版本，外显子明细留在本地。比较 ENST00000690252 和 ENST00000691502 时，两侧各有 13 个不同的外显子 ID，交集为 10，与直接读取原记录计算一致。此回放检验数据路径，真实模型会不会在需要时主动打开正确字段，还需在线任务验证。
