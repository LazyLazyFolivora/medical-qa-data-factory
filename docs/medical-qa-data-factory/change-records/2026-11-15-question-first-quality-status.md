## 真实出题观察

- **APOE 功能题**：题干问“APOE基因编码的蛋白质在脂蛋白代谢中的主要功能是什么？”独立、自然，所引 RefSeq 功能说明能支撑候选答案。它证明基础知识题可形成，不代表复杂整合题的能力。
- **APOE 疾病题**：“APOE基因发生突变会导致哪种特定的脂质代谢疾病？”仍有突变范围和必然性表述疑虑，不因发布而计为完全合格。
- **HBB 聚合题**：询问 HbS 聚合条件与红细胞形态改变，属于独立机制疑问，所引概述直接描述对应关系。
- **EGFR 联用题**：曾把“细胞增殖”错写成“受体增殖”。取消候选评审会放过这种错误，未采用该方案。
- **BRCA1/BRCA2 分工题**：题干是独立的角色比较问题；最终盲答额外添加“早期步骤”，当前引用未直接表述该细节，答案仍需逐句审计。
- **BRCA1-CtIP 机制题**：材料确实读到了正文，但候选把多项尚不明确的关系合在一个问题里，反复补证及修订。获取正文不是质量问题的充分解决方案。

## 未采用的实验

- 增加“检查措辞”的一句指令、缩短 form prompt、单独校对文字，默认模式均未稳定发现同一错指。
- 同一 Qwen 请求思考模式，配合明确文字校对任务，发现了 EGFR 错指，三个对照题通过；正式原 prompt 单独开启该设置仍漏错。成本更高，未改默认配置。
- CFTR 的“促进因素/必要条件”范围问题，在增加支持句与限制句、请求思考模式、先抽取原文观察后再审计等实验中仍被误判。不得把这些实验解释成已解决幻觉。
- 原文观察索引用程序编号回取真实句子，可以避免模型拼接引文，但不能保证模型对条件的归组和解释正确。

## 16:12 新发现：材料可见与正确理解是两个问题

BRCA1 新轮的“人类的BRCA1基因包含多少个外显子，其覆盖的DNA长度约为多少？”沿用了 RefSeq 说明中的“22 / 110 kb”，同一记录的当前 `genomicinfo` 却有 `exoncount: 31` 和不同基因区间。尚未核清注释版本、计数口径和转录本定义，不能直接宣布哪个数字客观错误，更不能当作无条件唯一答案发布。

验证器旧视图直接显示说明，结构化数组需多层读取。现增加有界集合索引；极小平坦表在总预算内显示完整原值，较大集合仍分页读取。每项最多 8 行、完整 JSON 最多 500 字符；索引总预算最多 2000 字符，引用数量最多 16。完整表放不下时退回裸引用。已审查并检查预算、分页、JSON Pointer 和回退行为。

但是三次真实同题回放（`collection-index-20261115-160635`、`collection-guidance-20261115-160725`、`small-collection-values-20261115-160832`）全部仍判支持，只引用说明文字；最后一次输入已经直接包含 31。临时追加的阅读指引没有效果，已移除。该改动只改善材料可达性和可见性，不宣称解决答案核验漏判。后续不能继续把此例归因于上下文太小。

BRCA1 两项发布题分别问 BASC 名称和 C 端结构域互作复合物。原文直接支持候选名称，但“与哪些复合物相互作用”的题干没有完整集合边界，不能仅凭原文提到一类就当作穷尽答案。这也是已发布数仍不能作为目标达成指标的原因。

## 16:18 两个执行问题的实证

- APOE 来源模式生成答案时，三次把 anchor ID 或虚构 `claim.1` 写入 `candidate_claim_ids`，在生成后被宿主拒绝。这不是生物医学推理问题。现把原本只写在指令中的来源模式约束落实到专用输出 schema：`evidence_basis=source_passages`，`candidate_claim_ids` 必须为空；原始生成和修订均使用。原 claim 模式不变，不静默删除模型字段。历史错误响应可在 provider 验证处捕获，真实相同输入回放 `source-design-schema-20261115-161617` 一次成功，原问题保留。代码已审查。
- APOE 组合实验的 form-reader 至少五次 `finish_reason=length`、输出 4096 token；一个样例输入仅 1415 token。独立提高输出额度至 8192 回放 `review-output-budget-20261115-161342`，四个题干均得到完整评审。但本次实际只用 3407 输出 token，不能据此断言增加额度是成功原因；随机输出长度仍需考虑。未修改默认模型或实验 runner 的全局配置，未把请求思考模式当作可靠性保证。

APOE 后续候选把药理抑制 NHE6 与遗传缺失 NHE6 的实验结论混为同一干预效果。验证正确指出斑块结论的干预条件不同；但“低 pH / 进一步降低 pH”的机制解释尚需查明，不能凭模型假定单调关系就断言科学矛盾。多次修订中出现了改问单次动物实验观测的偏移，不能计作成功。最终另一题“ApoE4如何通过内体运输机制影响细胞表面受体的表达水平？”到达 RELEASE_REVIEWED，随后在仅 3 步的断点续跑 `apoe-20261115-161927` 第一步实际发布，累计 2 发布，原目标仍为 4。

该题的基本信息需求符合领域机制提问方向，原文 PMID35298921 确实讨论受体滞留和细胞表面水平下降。但冻结答案把 molten-globule 与多种受体的行为串成一条共同机制；原文分别描述 apoER2 的构象/运输关系及 IR 聚集滞留，仍须核对是否过度合并。不能把“题干方向正确”进一步写成“最终答案全部正确”。

`apoe-20261115-161927` 已完成 3 步窗口，累计仍为 2 发布；后两步修订和评审 NHE6 候选。它再次改问两种干预的观测效果，不能以修订成功代替选题目标达成。本轮全部真实进程已结束，没有遗留后台试跑。
