# 默认领域问题，而非试验指标摘录

## 原因

原运行的主 agent 把 focus 写成具体 ORR/PFS 指标，问题发现据此提出试验结果机会，主 agent 又以数字完整、容易回答选择 ACHILLES。出题为保留证据范围，把试验名称写进题干。原 skill 对研究型问题的例外缺少任务前提，程序的设计提示也明确允许自包含的 study-specific comparisons。

## 修改

- 主 agent、问题发现、设计：先定义独立成立的领域疑问；用户只给实体不等于要求查询某项试验。专业领域条件可以出现，材料定位不成为默认前提。
- 研究型指标查询只在用户明确指定研究或任务明确要求研究型问题时适用。收紧事实选择参考中的例外。
- 缺少比较证据时补查或换领域信息需求，不得退回某篇论文的单个数字；不能删除试验名把样本估计写成总体固定属性。
- 主 agent 须实际回应 needs_evidence 的缺口，不能以“跨试验比较”改名代替补证。
- 同步 question_discovery.py 和 question_design.py 的实际 payload 指令，覆盖直接原文模式及事实模式；候选评审同步任务边界。
- 没有新增关键词过滤器或强制多篇论文规则。

## 同材料真实对照

两轮均恢复 `egfr-fresh-reading-memory-20261113-175935/before-design.json`，保留全部原始检索和已读结果，不手选问题、不复用旧机会及候选。

### 第一轮

`data/experiments/egfr-domain-question-replay-20261113-183156`。

仍失败：模型把“9.4个月”写成给定患者群体一线奥希替尼治疗的 PFS，中位数实际来自 UNICORN。题干不写试验名不意味着问题已泛化。问题发现提出补证缺口，主 agent 仍选择出题。基于此补充了上述样本估计、缺口处理和禁止缩水成数字题的指引。

### 第二轮

`data/experiments/egfr-domain-question-replay2-20261113-183428`。

主 agent 转向突变和不同代际 TKI 响应关系，尝试结构论文但两次原文选择调用失败，随后使用摘要机会。产生一个候选，询问哪些少见 EGFR 突变对第二代 TKI 的缓解率通常更高。

方向有变化，但不能判为合格：

- 题干仍使用“系统综述数据显示”的来源框架，并提前举出两个答案。
- EXACT_SET 答案漏了原摘要明确列出的 E709-T710delinsD。
- 答案加入复合突变，但原摘要仅说明相关复合突变对第二、三代缓解率均超过 50%，未直接支持第二代更高。
- 未运行最终验证或发布。这两轮只是选题与出题实际行为的对照，不证明稳定质量。

代码及指引已静态复核，无高、中严重性问题；本轮以真实模型轨迹验证，没有运行单元测试。每轮的 prompt-and-output.md 保存输入输出，after.json 保存实际候选。
