## 已观察到的题目

1. 在 NRF1 的直接蛋白质相互作用伙伴中，哪一个是 ATP 结合盒（ABC）转运蛋白家族的成员？
   - 候选答案 ABCA17P；候选自己同时标出 ABCF3 可能构成并列答案、ABCA17P 是假基因。
   - 质量评审多次 REJECT；盲答及复核却通过，仅凭一条 ABCA17P—NRF1 图谱边和名称 ABC 推断完整答案。
   - 独立难度评估为 easy。我的判断：当前证据不能支持唯一性，不能把数据库 gene/protein 边直接扩写为已确认的“直接蛋白质相互作用”；不应入库。
2. 在人类转录因子 NRF1 的直接蛋白质相互作用蛋白中，属于 ATP 结合盒（ABC）转运蛋白家族命名规则的成员有哪些？
   - 实际题干改成复数和“命名规则”，仍未定义合理完整的答案集合。
   - 主 Agent 认为已加入“伪基因”筛选条件，但实际题干没有。其叙述不能当作工具完成结果。
   - 质量评审 REJECT。我的判断：拒绝方向合理，但评审把需要外部分类知识说成违反题干自包含，这个理由不合理。自包含是读者不需要内部背景，不等于禁止外部检索。

## 机制暴露的问题

- 出题仍从现有边拼筛选条件，而非先建立自然、有价值且可查证的问题机会；两跳不自动等于困难。
- 主 Agent 会将计划、失败改写与真实候选混淆，曾把 ABC 题当成 E2F6 路径题，尝试发布被拒绝的候选；发布门槛成功拦截。
- 复核把名称暗示当作直接证据，没有证明答案唯一、完整；难度评估也引用此推断。
- 补证直接以候选答案 ABCA17P 搜索相同图谱，不是真正从公开题干独立寻找答案。
- 工具协议仍有可用性缺陷：长哈希 ID 抄错；嵌套查询字典被转换为 symbol 字符串，出现 {'symbol': 'ABCF3'} 整段当基因名的请求。
- 网络错误与科学证据不足须区分：重跑中 NCBI 返回 HTTP 500，Ensembl 有成功结果，不能全部归结为模型能力。
- 首轮受限试验还出现 NRF1/NFE2L1 混用和猜测图谱关系名，不可把这类查询的空结果当成该实体没有相关关系。

## 独立事实核查

NCBI 将人类 ABCA17P 标为 pseudo，而 ABCF3 标为 protein coding。公开原始论文指出人 ABCA17P 转录本存在妨碍形成真正 ABC 转运蛋白的突变。因此本试验把 ABCA17P 直接作为蛋白质答案尤其需要核实，不能靠命名确定。
