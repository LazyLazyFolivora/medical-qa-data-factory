# 固定材料出题调试

## 问题

完整运行虽然发布了一题，但前期反复阅读、整合时扩大因果问题、出题时将机制写进题干猜名称，评审还曾将“未直接证明”误判成“事实相反”。需要隔离检索和编排，只看材料如何变成题目。

## 本次实验

固定 Qwen3.6-FP8 和已有摘要，保留完整请求、响应与失败样本。先重跑原出题请求三次，再将阅读、选题、正式出题拆开检查。逐段观察发现：中间笔记也会新增因果解释和错误译名，增加调用并不自动改善结果。

继续比较简短原文出题、原文句子编号、评审与修订、思考模式，以及英文起草后中文转写。共 81 次实际调用，总用量 134217 tokens，详见实验 manifest。思考模式只用于对照，没有更改默认配置。

## 结果

形成可用的选题方法：围绕原文明示的对象／模型与病程、干预和观察结果提问，公开最小必要背景，结果留在答案里；遇到缺陷，根据原文给具体反馈，保留原信息需求做最小修订。

最终两份摘要各三次出题和中文转写，两个初始样本可保留，四个存在词语、范围或强度问题。四个样本经独立 agent 审查给出具体缺陷后，Qwen 完成了局部修订；核心问答复核无新的阻塞错误。部分证据映射元数据仍需整理。六份是重复实验样本，不是六道不同题目。

不能据此声称全自动稳定、跨实体泛化或困难题能力。Qwen 自身评审存在漏检，本文的修订效果包含独立审查提供的反馈。基线和改进同时改变多个变量，属于方法组合比较，不是单因素消融。
