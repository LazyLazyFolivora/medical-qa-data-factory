# 困难题验证：有意义的比较不等于困难检索

## 结论

本次固定材料实验验证了：补充相关正文后，Qwen 可以提出有意义、答案有依据的细胞类型对照题。但尚未验证出稳定的困难题能力。三次全文组生成均自标 hard，实际只是同一个比较需求的三个变体，不是三道独立困难题。人工审查暂归简单至中等的比较检索候选；难度需要后续实际动作、成本与成功率标定。

本次没有修改生产链路、生产 skill、模型默认配置或发布题目。实验材料由调试者选择，因此也不能证明 agent 能自主检索到这些材料。

## 实验条件与文件

- 模型：Qwen3.6-FP8，enable_thinking=false，max_tokens=4096。完整实际请求保存在每个子目录的 request.json，采样参数以这些请求为准；没有种子控制的统计实验。
- 目录：`data/experiments/hard-question-probe-20261111`。
- `limited-1..3`：原有两份摘要，3 次出题。
- `full-1..3`：补充主题相关材料，3 次出题。
- `blind-1..3`：只给公开题干，不提供参考答案、文献或出题标签，3 次检索计划。只是计划，不是已执行搜索。
- `shortcut-2/3`：只给一篇 2025 年论文，测试是否覆盖两个版本的题目，2 次。
- 总计 11 次模型调用，逐次保留 request、原始 response 和解析 output。
- 浏览器工具另外执行一次实际检索：`EGFR myeloid proximal tubule deletion recovery ischemic kidney injury`，返回 40379634 和 22418982 的 PubMed/PMC 条目。该查询只使用题面实体和条件，没有加入延迟/加速等答案。

## 材料的实际范围

1. PMID 22418982：下载到正文 XML，43 个 body 段落及摘要。近端小管特异性 EGFR 删除与缺血损伤后恢复。
2. PMID 40379634：下载到正文 XML，83 个 body 段落及摘要。髓系 EGFR 删除、胞葬和中性粒细胞凋亡。
3. PMID 30072422：只有摘要；Europe PMC fullTextXML 返回 HTTP 500，状态已保存。不得把 `full-sources.json` 理解为三篇全文均成功。

段落编号是此次本地解析产生的编号，需与保存的 XML/JSON 绑定。解析包含图注，并非纯正文自然段。

## 输出及逐项审查

摘要组 3/3 返回 hard_candidate_supported=false。部分替代题仍存在跨背景生硬拼接或难度标定不一致，不能据此宣称提示词可靠。

全文组最好的候选是 full-3，其中文释义为：

> 在小鼠缺血性急性肾损伤模型中，分别在肾近端小管上皮细胞和髓系细胞中敲除 EGFR，对肾功能恢复有何不同影响？

答案：近端小管上皮细胞中敲除会延缓恢复，髓系细胞中敲除则加快恢复。

- 22418982 P4/P12/P14 支持前半：初始损伤相近，第 6 天敲除组 BUN/肌酐仍较高。
- 40379634 P4 支持后半：初始损伤相近，敲除组 BUN 下降更快。
- 两项独立研究可以比较方向，不能当作同一实验比较效应大小或恢复快多少。
- full-1/2 公开题干遗漏小鼠范围；证据元数据里的 scope 无法弥补。
- full-2 询问恢复时间进程，答案却只给方向；其 Mcl-1 说法需要 abstract/P33/P34/P45 等支持，原引用不足；ERK/Akt 机制宜保留“伴随/研究提示”，不宜写成完全确定的因果证明。

## 为什么尚不构成已验证的困难题

三个设计输出都标 hard，但：

1. 两个检索分支可由公开题干一次确定，不必先发现未知中间实体再调整查询。
2. 实际一次普通检索即出现两侧原论文标题和摘要，足以形成方向性答案并回查原文。
3. 40379634 P1/P41 已概述上皮 EGFR 对恢复的重要性，P4/P40 给出髓系删除加快恢复的结果。它提供对比的主要线索；严格确认“近端小管特异性删除”仍应回查 22418982。
4. full-2 自己承认单篇讨论段可能提供捷径，仍标 hard；full-3 断言单篇不包含对比且把近端小管结果的含义说反。这说明模型自报难度不能作为验证结果。

盲计划三次均标 medium，但也出现猜测性机制、扩大比较终点等问题；它不是可信的难度裁判，只能帮助提出待实测检索路径。

单篇覆盖实验 **没有成功直接完整回答**：shortcut-2/3 均返回 fully_supported=false，并把缺口过度理解为必须在同一篇做直接对照。shortcut-3 更把近端小管/髓系的比较换成髓系/中性粒细胞，并错误开头称两侧都加快恢复。因此，不能宣称“模型只读一篇已答对”，更不能把回答失败当作困难证明。困难标签不足的主要依据是实际搜索存在简单路径以及原文可核对的线索，而不是该单篇答题器的成功率。

## 下一步应验证什么

保留这个有意义的比较题，先不计为困难产出。困难出题应寻找值得回答的证据缺口，例如需要先明确条件/发现中间关系，再决定后续检索，或对不同实验条件进行必要的证据综合。生成后用题干驱动的实际搜索检查是否有更短路线；有捷径就降级，不为了达到 hard 标签强塞问题或隐藏必要条件。

这不是“一篇永远简单、多篇才困难”的规则。需要的是实际检索与整合工作量；本次只发现这些候选的 hard 理由不充分，没有建立通用难度阈值。
