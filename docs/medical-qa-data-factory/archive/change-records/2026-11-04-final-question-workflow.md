# 固定题干后独立验证

旧流程先验证候选，再把候选写成正式题目。读者最后看到的题干可能和盲答时不同。候选初审、答案比较、反例检查和发布复核也会多次判断同一个问题。

新建的 CLI 和 Web 任务使用 objective-hierarchical-loop-v2。出题阶段从事实中选择可独立检索的问题，一次写出完整题干并留下私有预期答案。独立检索按题干选源，盲答只使用公开题干和独立材料。复核对照冻结的盲答、预期答案和证据，判断题目是否自足、答案是否完整、证据是否直接支持，并评定实际难度。

通过后原样发布盲答使用的题干。证据不足时记录具体缺口，交回有预算上限的补证循环。题干缺少必要条件时把修改意见交回出题环节。若已有直接支持，其他检索没有命中本身不构成否决理由。

旧任务按原版本续跑。自动测试覆盖盲答输入隔离、题干一致性、发布可见性及证据不足等分支。发布率和人工评审质量仍需用新的真实任务比较。
