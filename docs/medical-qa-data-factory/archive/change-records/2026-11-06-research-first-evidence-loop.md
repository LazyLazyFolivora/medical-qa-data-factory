# 原文研究到综合题：实际链路迭代

分支：`experiment/research-before-question`。本实验独立于生产生成链路，不发布题目、不修改生产数据库。

## 目标和验收范围

从实际资料中形成有边界的综合认识，再反向概括一个自然、自包含的信息需求。最终面向 query-planner 的动作选择训练；本次先验证“材料能否支撑综合问题”，不能仅凭一道题就证明训练价值或难度标签成立。

固定材料实验使用 PMID 27786612 的原始研究。该文来自此前对 EGFR 图谱线索和 PubMed 检索的人工审计；后续轮次预先给定该文，部分轮次还人工限定了模型对照这一研究方向。因此这些轮次不是从实体开始的全自主发现能力证明。

原文入口：https://pmc.ncbi.nlm.nih.gov/articles/PMC5240640/

## 本次看到的实际问题

1. **下载全文不等于阅读全文。** 模型从摘要或索引预览生成了详细机制结论，有时只读 offset 0 的引言便准备结束。
2. **旧认识反复复制。** 每次工具动作要求完整重写 understanding，让未经证实的推断在后续轮次不断重复。已经解决的缺口也未删除。
3. **阅读片段截断对照。** 固定 4500 字符片段会在关键结果中间结束；模型据此扩大结论或另找不相关资料。
4. **研究焦点在出题阶段丢失。** 出题只收到认识和材料，没有明确收到 research_focus，容易重新扩展为整个药物机制综述。
5. **评审也会错。** 曾把 ADCP 没有显著增强说成增强；把无显著抑制说成完全无效；将受体总量下降等同于已证明的具体细胞清除机制。还有评审自行添加未经材料支持的裸鼠免疫细胞缺失描述，随后污染研究认识。
6. **重复全文污染上下文。** 同一篇文章多次 details 产生新 ID 和重复索引、片段，v7 最终触发上下文超限。

## 实现改动

- `generation/research_documents.py`：补 Europe PMC 开放全文入口，保存原文，建立章节、段落 ID、字符位置索引。获取失败保留实际原因。
- `generation/research_first_pilot.py`：read 支持选择最多四个完整段落；长段落保留续读位置；同一正文重复获取复用既有 ID。每份正文展示的已读片段设有限额。
- 非 finish 动作只需说明下一步目的，不要求先写整篇理解；finish 必须提供本轮认识。
- 暂定完成时进行原文复核；具体缺口回给研究者，由模型决定补读、补查或收窄认识。复核只收到当前认识及原文，不把旧评审历史当证据。
- 复核优先展示认识引用的来源；不可见引用不能被当作通过依据。
- 出题接收 research_focus，要求保留影响结论的模型和对照条件。
- 实验 skill 增加读后修订、结果与推断区分、未解决机制边界、整合型问题的信息需求指导。

这些修改没有把检索方向或答案写成硬编码规则。代码提供读取和反馈机制；研究方向、段落选择、结论和题目仍由模型选择。

## 人工核查时必须保留的原文边界

- p12：H1975-HGF 是人为表达人的 HGF 的模型，原文描述为自分泌激活；不能改成普通共表达或旁分泌实验。
- p13：H1975 中 Fc 沉默和 c-Met 单臂对照相对 PBS 未见显著活性；完整低岩藻糖基化双抗及 EGFR 单臂的 TGI 分别为 79% 和 81%。无显著活性不等于证明绝对零作用。
- p14：H1975-HGF 中 Fc 沉默、c-Met 单臂和 EGFR 单臂都表现出部分抑制，完整双抗抑制最强。不能把 H1975 的结果推广到所有模型。
- p15：H1975-HGF 药效学实验中，完整双抗降低总 EGFR、总 c-Met；Fc 沉默未显著降低这两个受体的总量，但降低 p-Met。必须区分磷酸化、总受体量和肿瘤生长这三个终点。
- 体外磷酸化抑制相似、体内抑瘤表现不同，支持不能只凭该体外指标评估作用；并不证明总受体下降是全部体内疗效的唯一原因，也未定量分配各免疫效应的贡献。
- p11 的 LF/NF ADCP 结果统计相当，不能和 ADCC 的增强合并描述。

## 仍需单独验证的能力

一篇全文内比较多个条件可能需要整合，但“读全文”不自动等于困难。须比较摘要检索、全文阅读、不同来源检索等动作实际能否完成该题及其代价，才能判断它是否适合作为动作选择器的训练样本。固定材料中的合格题也不能替代多实体自主检索成功率测试。
