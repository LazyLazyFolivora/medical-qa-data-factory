## 题目质量核对

以下仅对照本次实际保存的摘要，不是独立全文复核。

1. Esculetin 抑制哪条信号轴：题干明确腺嘌呤诱导的肾损伤小鼠模型，来源为 PMID42075834，作为少检索的直接事实题可以保留；仍是单篇材料提取。
2. EZH2 耗竭后哪些 EGFR 下游分子的磷酸化受抑：答案 ERK1/2、STAT3 在 PMID37029114 中有直接文本支持。但公开题干没有保留小鼠模型及体外实验范围，评审却声称它已限定该范围。内部 proposed_public_scope 被当成公开题干的一部分，问题仍在。
3. WT 与 Wa-2 小鼠在缺血损伤后第 2 天、第 28 天的修复和纤维化差异：公开题干包含模型、比较对象和时间点，答案与 PMID23684791 摘要对应。四题中更符合有意义的比较问题，但仍可由单篇摘要回答，不应称为已验证的多路检索题。
4. EGFR 通过哪条通路诱导 SOX9：Akt-YAP/TAZ 与 PMID40892469 摘要结果对应；公开题干省略小鼠及细胞实验范围，应进一步审查泛化。题目中英文混用，也尚未形成统一输出语言。

## 流程问题

- 实际研究方向比上一轮更具体，并使用了证据整合；上一轮同实体目标 5 题只发布 1 题，本轮发布 4 题。但只有各一次随机运行，不能证明稳定改善。
- 整合工具会列出正文细节缺口，主 agent 选择缩小出题范围，继续基于摘要出题。这本身不必强制纠正；如果希望发现新的问题，需要检查它是否探索了有价值的缺口，而不是只统计全文调用次数。
- 7 次 tool_feedback：4 次缺已验证的发布提案；3 次同时传入 research_id 与 source_sections。它最后能恢复，但仍浪费动作。
- 模型有时把验证完成描述成已发布，或称已有验证提案后又说要生成提案。文字解释仍不能作为执行事实。
- 4/5 时停止，理由开头称达到目标，后文又承认少 1 题；理由主要是当前未读材料不适合继续。它没有据此探索 EGFR 的其他方向，不能证明整个实体无合理方向。
