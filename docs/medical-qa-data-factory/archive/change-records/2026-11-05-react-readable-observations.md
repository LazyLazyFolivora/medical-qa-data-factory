# 让 ReAct 主 Agent 看清最新工具结果

## 问题证据

真实试跑 react-live-brca1-20261105-d 最后查询返回了 50 条疾病/药物相关材料，模型却沿用“只有组织分布”的旧判断停止。原索引把 JSON 的前 360 字符直接当预览，材料/锚点常先显示长 ID 和哈希；最新观察也未直接展示检索材料、候选事实和实际候选题。

## 改动

新增 generation/react_observations.py，负责对存储记录做确定性的可读投影，不判断研究价值或选择路线：

- 材料、证据锚点预览优先显示 quoted_text；事实显示主体、关系、对象、条件；候选显示实际题干、候选答案、范围、风险。
- 最近检索直接显示状态、返回数量、错误和前 12 条材料内容卡片。保持来源顺序，不做相关性排名。明确遗漏数量，全部 ID 和原文仍可通过 read_artifacts 获取。
- 最新工具结果在 recent observations 中优先展示，保留已有 16000 字符内容预算和截断提示；latest_step 提供动作及有限结果引用、总数。
- read_artifacts 的正文顺序改为可读内容在前、存储元数据在后；索引分页也显示内容卡片。
- 标注 research_note 是可能过时的模型便签；提示模型用最新工具结果更新判断。skill 要求停止前核对最近结果，修订后核对实际题干。

没有增加强制继续、强制出题或程序替模型判定方向的规则。模型仍可 stop；回归测试明确保留这一点。

## 验证

相关回归 68 项通过，覆盖主循环、Web、CLI、连续生产、历史压缩。新增测试检查：组织材料之后的新疾病关系出现在最新观察中；实际题干和答案被展示；50 条结果只展示 12 条时明确说明剩余 38 条。
