# 出题策略与独立难度评估

原流程由同一个通用事实组合方法出题，难度主要通过参考说明传入。困难目标容易继续收集名称、编号和位置字段，最终复核还同时负责答案与难度判断。困难题的目标计数也未排除较低难度产出。

现在由 `generation_strategy` 选择 easy、medium、hard 或 free。默认 auto 在单难度任务中采用对应策略，在多难度或未指定难度时采用 free。策略定义检索目标、材料组织方法、缺口处理和备用数据源顺序。检索规划和出题使用同一个策略，仍共用模型调用、证据和运行记录基础设施。

easy 寻找直接支持的有用事实；medium 寻找必要关系连接或条件筛选；hard 寻找必要多步整合、有效条件交叉或有限候选比较；free 根据材料支持的信息需求自由形成问题。困难策略不保证每道产出都达到困难级别，也不能为了多跳而制造无证据的关系。

新版单实体流程在题目通过答案验证后，调用独立的 `objective_difficulty_assessment` 角色。它只收到最终题干、已验证答案、支持证据和 planner 工具环境，不接收目标难度、生成策略或作者预估。结果保存最短合理解题步骤、必要整合、捷径与判定理由。

实际难度写入发布报告；独立评估记录关联生成策略和候选，报告保存对应评估记录 ID。较低难度的合格题照常保存，困难目标只计困难题，中等目标只计中等题。独立评估失败进入可恢复状态，避免把服务故障当作题目不合格。

自动出题页面支持选择策略，题目详情显示独立难度判断及理由。CLI 使用 `--difficulty` 和 `--generation-strategy`，Web 请求使用同名下划线字段。已有断点缺少策略字段时按 auto 解析，旧发布报告仍可读取。历史旧版多阶段发布流程继续使用其原有审查方式。

这次改动提供可选择的四种策略和独立评估能力。按均衡或中间多两端少的比例自动调节策略调用次数，仍需要数据集级分布调度。真实困难题产出率需要用实际材料与模型运行评估。
