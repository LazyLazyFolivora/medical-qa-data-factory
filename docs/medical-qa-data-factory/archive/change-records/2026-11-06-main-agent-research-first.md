# 主 ReAct 链路接入研究后出题

## 改动目标

将实验中形成的方法接入正式主链路：读取真实资料，比较条件和结果，发现值得解释的差异或联系，形成有边界的认识，再反向概括问题。允许论文研究型问题；客观正确和必要背景完整是基本要求，难度及动作选择训练价值另行评估。

不是把任务改成固定状态机，也不是新增一组业务拒绝规则。主 LLM 仍选择查询、来源、段落、研究问题、出题时机、修订、验证和发布。

## 具体调用链

CLI `objective generate` 和 Web 创建/恢复任务都使用 `ObjectiveQuestionAgentLoop` + `ReactMainAgent`，本次修改直接作用于这些入口。

1. `ReactMainAgent.decide`：提供研究方法、可用工具、实际观察和已保存研究整理的索引。图谱与未处理材料是可选线索，不是必须逐个清空的任务列表。
2. `retrieve_materials` / `read_source_details`：获取原始资料。PubMed 原有全文入口不足时增加 Europe PMC 后备；正文保存上限由 16,000 提到 180,000 字符，避免结果段直接丢失。长正文不直接全部交给整理模型。
3. `read_artifacts(source_view=true)`：返回原文段落索引；`paragraph_ids` 读取选段，`index_offset` 浏览后续索引。超长段按稳定偏移拆成片段，并标记续读位置。
4. `synthesize_evidence(research_question, source_sections)`：读取模型选中的原文段落，整理条件、对照、终点和结果；输出观察、联系、综合认识、一个 `question_focus`、`answer_boundaries` 和缺口。原文及定位独立保存，模型解释不成为证据。
5. `understand_facts(research_id)`：从该研究选中的原文提取事实，创建保留原材料字符偏移的锚点并保存。部分选段提取不会宣称整篇论文已经处理完。简单资料仍支持原有不传 `research_id` 的方式。
6. `design_questions(claim_ids, research_id, design_instruction)`：将明确选中的研究焦点、答案边界和对应原文传给设计模型。移除原先自动传入“最近三份模型研究摘要”的行为；不传研究整理中的整篇机制解释作为答案依据。
7. 候选评审、独立补证、盲答/答案验证和显式发布保持原有入口。评审可以要求修题或补证，但不能仅因题目像论文阅读题、术语专业或来自单篇原文就否定。

示例工具参数中的材料和研究 ID 必须来自当次真实返回，不可复制固定样例 ID。

## 信息传递原则

- `research_id` 指向一份具体整理结果，不靠“最近的摘要”猜测当前研究主题。
- 传给设计的 `research_context` 只包含焦点、边界、原文，不包含整篇 `integrated_understanding`。候选事实仍必须对照原文核实。
- 研究整理的原文总选择量最多 16,000 字符；不重复发送原文正文和副本，保留轻量位置列表。
- “未见显著效果”与“完全无效”、观测变化与具体机制、不同模型和终点，均要求在研究、提取与出题中区分。
- 工作笔记只记录简短新增观察与缺口，不在每次阅读前重写长篇机制解释。旧解释被新证据推翻时更新。

## 实际验证

新增贯通测试覆盖：正文索引 → 选段整理 → 保留偏移的事实提取 → 指定研究焦点进入出题；断言旧机制解释不会进入设计请求，派生锚点能从原始存储回读。另测试总材料预算和全文后备取回引言后的结果段。

第一轮正式 CLI：`main-research-first-egfr-20261106`，PrimeKG + PubMed、18 个动作。观察到 agent 花费较多动作逐条阅读解剖关联，动作预算结束时尚未产题。据此补充主 skill 与困难策略：图谱邻居不是必读清单，优先选择有意义的线索查原始研究。

第二轮正式 CLI：`main-research-first-jnj-20261106`，输入 JNJ-61186372、PubMed。实际选择了 PALOMA-3 / MARIPOSA 相关研究，执行了检索、阅读、事实提取及 `synthesize_evidence`。期间出现把不同材料的段落编号混用，错误反馈已补具体材料和可用 ID，保留原始失败记录。首次 16 动作达到预算后从断点继续验证，未把“已接入”当成质量已经通过。

完整请求、返回、动作和工具结果保存在上述任务的 `debug_trace`。代码测试通过只能证明接口和传递行为，不能替代对真实题目答案的原文核对。

## 本次结束时的观察

- 98项相关测试通过，代码审查通过。
- JNJ任务断点续跑12动作后，实际生成2个候选并执行了候选评审；发布数为0，停在动作预算。真实设计请求中已经出现选定的`research_id`、`research_question`、`question_focus`、`answer_boundaries`和对应`source_passages`，证明不是只改了提示文档。
- 两个候选分别涉及PALOMA-3研究内比较和PALOMA-3/MARIPOSA跨研究比较。后者仍存在将不同研究对照连成同一给药途径问题的风险，没有作为合格产出。
- 模型对第一个候选给出REJECT，但其部分理由（仅因不同终点并列就拒绝、研究别名容易混淆等）不能直接当作正确判决。需核对实际人群标签与统计措辞，而不是机械拆成简单属性题。已针对该实跑反馈补充研究与评审skill，后续语义效果仍需实测。
- 结论是正式链路的研究—设计传递已经接通；尚未证明自动答案准确率和候选评审稳定达标。没有将人工校订的历史样例计为这两次实跑产出。
