# 自动证据整理实验

## 范围与实现

2026-11-02，延续固定 BCL2 机会实验。新增 `pilot-evidence-preparation` skill 和
`src/medical_qa_data_factory/evidence_preparation_pilot.py` 实验入口。

输入仍为人工审阅后的信息需求、完整原摘要、完整的已保存 UniProt 补查结果。
本轮特意不把人工填写的 relation、connection_value、lookup_entity 传给整理模型，
避免它只是照抄已审阅的关系答案。资料本身包含对象名称，这是出题准备阶段所需的证据。

每次运行：模型整理观察与证据 → 原样交给未改动的写作 skill → 保存题目。
写作者只看到任务和模型整理的证据包，不再看到完整原文或人工精选片段。
没有自动修复、重新检索、图谱调用或独立答题验证。

## 复现

在项目根目录执行，输出目录须是新目录：

```powershell
$env:PYTHONPATH='src'
$env:PYTHONIOENCODING='utf-8'
D:\Anaconda\envs\qa_env\python.exe -m medical_qa_data_factory.evidence_preparation_pilot --input data/experiments/pnma1-fixed-writing-01/writing-materials.json --output data/experiments/pnma1-preparation-new --trials 3 --config config/models.json --provider qwen-self-hosted
```

`preparation-materials.json` 保存实际输入；每个 trial 保存整理请求、响应、写作输入和写作请求、响应。
实际 skill 全文和版本散列保存在各次 request 中，当前文件变更不影响追溯。
`review.md` 是未经人工改写的题目及模型自述，不能当作质量审查结论。

## 两轮结果

两轮各三次整理和三次写作，共十二次真实模型调用，均完成。

| 运行目录（data/experiments 下） | 改动 | 人工阅读观察 |
|---|---|---|
| pnma1-evidence-preparation-01 | 首版整理 skill | 三次选择正确的 BCL2 关系原句和抗凋亡功能原句，species 均为未说明；但 observation.entity 均填 PNMA1，角色表达含混。全部只选择一般抗凋亡标签，未保留调控环节。边界说明还出现来源混淆、效应方向表述错误及与当前问题无关的缺口。 |
| pnma1-evidence-preparation-02 | 明确 entity 为干预对象；要求保留信息增量、区分范围边界与回答缺口 | 三次 entity 仍填 PNMA1，其中一次观察直接变成 PNMA1 过表达促进凋亡，偏离目标观察。三次仍只抽取抗凋亡标签，也仍把物种或直接结合细节列作缺口。此次修改没有解决关键问题。 |

两轮最终题目均保留“过表达抑制 PNMA1 诱导的神经元凋亡”这一关系，参考答案为 BCL2。
但写作者可以从引用中拾取 BCL2，即便 observation 字段错误也能形成通顺题干。
因此不能用最终文本通顺来证明证据整理理解正确。

第一轮 trial-2 的 boundaries 还把原论文的推测混称为数据库内容，
把机制上的“可能”移到了已观察的抑制作用上；这说明自由解释字段本身也会引入新错误。

## 这次真正暴露的问题

1. **角色没有读清。** 一个字段叫 entity 容易被当作种子实体；即使补充定义，当前模型仍重复此行为。
   下一步宜直接要求写出完整的“谁经过什么操作，改变了谁引起的什么效应”，
   先测试这句观察是否正确，而不是继续添加更多抽象字段。
2. **简短但信息不足。** 第一部分已要求识别能抑制凋亡的蛋白，第二部分仅回答“抗凋亡”，
   信息增量很弱。它可能是合理的简单问答，却不能因为两份来源就包装成中等题。
3. **边界与缺口仍混淆。** 不指定物种的观察题可以保留物种未说明；询问一般作用也不要求
   已证明直接结合或测过亲和力。缺少这些信息不自动妨碍当前题目。

当前 skill 是经过真实测试但仍未达到目标的实验版本，不迁入生产流程。
仅验证脚本能运行、原始输出可保存，原有三项 pilot 测试及 skill 格式检查通过；这些检查不代表题目质量通过。

## 下一步应缩小的实验

固定同一批原始资料，先让模型交付两项内容：

- 一句有原文依据、角色清楚的具体观察。
- 一项有原文依据、相较该观察确有新增内容的相关属性，并说明其如何服务于同一个信息需求。

先审阅这两项是否值得组合，再测试写作。允许只形成一项事实的简单题，
不要以必须生成关系题为由增加重复的第二问。
这是出题方法实验，不需要先增加评分器或发布门禁。
