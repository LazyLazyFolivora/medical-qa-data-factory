# 题干轻筛与训练样本导出

训练样本包含同一版本的完整题干、核验过的答案及出处，以及从该题干出发的示范检索轨迹。

1. 前置读者只看题干，判断问法是否自然、是否知道要查什么。简单问题、自然的一次多问、点名公开论文或试验的问题都可以保留。缺失关键指代时退回补齐。需要查论文、现有材料答不全，均可进入后续处理。
2. 题干确实断言了某个事实时，用原文核对这个前提。明确不成立时修题，证据尚不足时记录缺口并保留候选。答案错误时修答案，缺证据时补查。复用现有核验与修订流程。
3. 控制器宣告没有可继续的方向时，核对是否仍有已经审核通过、可起草的备用题。修订和复审重复遇到同一缺口时，优先推进备用题，保留未解决的候选。
4. 已发布题目的示范检索单独运行。示范策略读取完整题干及此前工具结果，从空证据开始，实际执行搜索。待训练的 query-planner 使用生成的动作示范做训练。每一步记录当时可见的证据、动作和工具结果，最后记录停止决策。
5. 导出时按题目版本关联已核验答案及其出处、示范轨迹。核对停止时的证据确实覆盖了完整题干。已有问答发布包可以继续用于审计，也可以作为示范检索的输入。

验证用例覆盖点名试验、缺关键指代、缺证据但题干成立、存在备用题却要结束，以及从已发布问答生成并导出一条示范轨迹。

在项目目录执行下列命令，从已有客观题发布包采集 PubMed 示范并导出 JSONL。需要已配置的结构化模型服务。可以重复传入 `--question-id` 选题。

```powershell
medical-qa-data-factory objective training-export --release <发布包目录> --output <训练样本.jsonl> --model-config <模型配置>
```

当前示范使用 PubMed 摘要和可获取的全文。每份材料最多向示范策略展示原文的前 12,000 个字符，截断会写入轨迹。输出以通过核验的示范为准，命令同时报告未导出的题目及原因。

导出格式保存原始的问答、出处和工具轨迹。现有 `query-planner/scripts/train_bc.py` 接收已编码的状态向量和动作特征，接入这份 JSONL 时还需要为文献检索动作定义相应编码。

出题时同时保存 `suggested_retrieval`，包含首条检索词、建议来源、预期证据和停止条件。它跟随题目进入发布包和训练样本。实际执行的动作和返回结果仍由检索记录保存。
